# Architecture decision records

Why a standing decision was made, one file per decision: `NNNN-title.md` with its status, context, the options weighed,
the decision, its consequences and when to revisit it. Once accepted, a record's text is not edited: a decision that changes
gets a new record that names the one it supersedes, and the old record's status line alone changes, to name the new one.

| ADR | Status | Decision |
|---|---|---|
| [0001](0001-a-paragraph-holds-inline-runs-shaped-as-one.md) | accepted | A `gui` text node is one paragraph with inline runs: `Text::span`/`Text::spans` take `Span`s (`span("…")`, `Styled`, `on_click`) resolved into `text::Run`s (range, `ResolvedText`, background, radius, padding) and shaped as one cosmic-text buffer (`set_rich_text`); glyphs carry their run in `metadata`, so colour, underline, strike and background are drawn per run; horizontal padding is letter spacing on a run's ends; a span with a handler or cursor is a `SpanTarget` hit by click and pointer |
| [0002](0002-code-is-highlighted-by-shikis-engine-in-rust.md) | accepted | Code blocks are highlighted by irosashi 0.3.1 (MIT, Shiki's TextMate engine in Rust, on ferroni BSD-2-Clause) with `github-light`/`github-dark` and `highlighter.ts`'s languages and aliases; one `Highlighter` per thread as a `gui` context value, 256 results kept; `ansi` follows Shiki's `tokenizeAnsiWithTheme` (theme `terminal.ansi*` colours, dim at half alpha) in `code_block/highlighter/ansi.rs` |
| [0003](0003-gradients-masks-and-filters-are-paint-in-gui.md) | accepted | `gui` paints CSS gradients, masks and filters: `style::Effects` (`background_image`, `mask`, `filters`) with `currentColor`-relative `Ink` and `Calc` stops resolved at paint, OKLab interpolation, `background-clip: text`, a node with a mask or filter painted as a group and composited; `scroll-fade` is a scroll-driven mask; `shimmer` is shadcn's utility in `crates/shadcn` |
| [0004](0004-direction-is-an-inherited-property-of-gui-nodes.md) | accepted | `style::Direction` is an inherited text property (`dir_rtl`, `dir_ltr`) passed to Taffy; `TextAlign::Start`/`End` resolve by it; `ms`/`me` margins land by it; `layout::location` puts an in-flow child of a right-to-left block against the right edge; right-to-left scrolling runs from the right, its wheel reversed and `scroll-fade-x` turned `to left`; Arabic falls back to the system's Geeza Pro |
| [0005](0005-gui-sets-text-as-blink-does.md) | accepted; baselines superseded by 0006 | `gui` text matches Blink: static Inter faces at optical sizes 16 to 32 chosen by size, baselines from rounded ascent and descent with the half-leading floored and snapped to device pixels (`css_baselines`), `WrapStyle::Pretty` re-breaking the last four lines, `tabular_nums` (`tnum`) |
| [0006](0006-gui-lays-out-in-fractions-and-snaps-at-paint.md) | accepted | `gui` lays out fractionally (Taffy rounding off) and snaps box edges, clips, images and shapes to device pixels at paint (`Bounds::snapped`); text measures round up to 1/64 px with no slack; min-content text is its widest word (`Breaks::Words`, `TextSystem::min_content`); a percentage-wide image adds nothing to min-content and keeps its ratio (`ImageMeasure`); baselines take the primary font's metrics and round to a device pixel at draw (`baseline`); cosmic-text from upstream `c5d3205` for the clamped last line |
| [0007](0007-gui-moves-as-css-does.md) | accepted | `gui` moves as CSS does: `Style.motion` declares transitions (`Properties`, css-transitions-1 reversal), keyframe animations (`Animation`: tw-animate's `enter`/`exit` with `fade`/`zoom`/`slide`, `accordion_down`/`up`, `spin`, `pulse`, `caret_blink`) and exits; `Motion` keys them by node path, keeps a leaving subtree painted and inert until its exit ends (reka's `Presence`); translate moves the box, scale and rotate and opacity below 1 paint as groups; reduced motion is `RunOptions.reduced_motion`; a `Scenario` frames states unless it plays motion, and `rest` judges a page at rest |
| [0008](0008-gui-measures-every-frame-and-holds-what-the-screen-shows.md) | accepted | Every `FrameReport` carries an `inspect::Footprint` (nodes, shaped text, glyph, icon, shadow, scaled-image and layer images with bytes, the reactive `Graph`, the heap from `gui::heap::COUNTING`, a `#[global_allocator]` a binary opts into); `inspect::Spread` is the one percentile rule; `cache::FrameCache` keeps what the last two frames drew (text, glyphs, icons, shadows, scaled images); an effect subscribes to what its last run read and forgets it when dropped; a shadow keeps only its bands around the clear middle; an image is scaled once per size; `docs --bench` (headless; `crates/shadcn/bench.sh` writes `bench.json` and compares with the run before, re-measuring a SLOWER page) fails a page whose steady p95 passes `--budget` (16 ms), that grows after a second pointer walk, or that got slower; F10 / `--hud` shows the frame HUD |
| [0009](0009-gui-speaks-to-input-methods-and-assistive-technology.md) | accepted | Text inputs take composed text from the platform's input method (`TextEdit::preedit`, shown underlined at the caret, the value only on commit; the window allows it while a composing input has focus and puts its candidates at the caret); each frame is an AccessKit tree (`access::tree`: roles from `Semantics` set as ARIA says them, or implied by content; ids from node paths) sent only while assistive technology listens, its `Click`, `Focus` and `SetValue` back as `Input::Act`; shadcn sets roles and states on its controls |
