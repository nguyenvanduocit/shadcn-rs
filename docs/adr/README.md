# Architecture decision records

Why a standing decision was made, one file per decision: `NNNN-title.md` with its status, context, the options weighed,
the decision, its consequences and when to revisit it. Once accepted, a record's text is not edited: a decision that changes
gets a new record that names the one it supersedes, and the old record's status line alone changes, to name the new one.
